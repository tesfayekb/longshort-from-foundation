# Combiner Model Trainer (FP-052.3 / 3.3b-ii-B)

Python LightGBM-LambdaRank trainer that produces the model artifact the
in-substrate TS inference seam (`supabase/functions/_shared/longshort-combiner/lgbm-inference.ts`)
consumes.

## Authority

- `docs/04-modules/longshort/` §6.1 / §6.2 — algorithm + objective LOCK (LightGBM, lambdarank, NDCG@25). Untouched.
- `docs/04-modules/longshort/` §6.3 — weekly Sunday cadence, exp-time-weight half-life 1.5y, walk-forward CV.
- `docs/04-modules/longshort/` §6.4 — 12-week retention (enforced in-substrate by MIG-116 / `purge_retired_combiner_artifacts`).
- `docs/04-modules/longshort/` §6.5 + DEC-066 §(c) — 18-feature representation (16 per-name + 2 appended market-level regime keys); `FEATURE_ORDER` is the load-bearing contract.
- DEC-064 — training-runtime SUBSTITUTION (Modal/Python → GitHub Actions Python job); hash-pinned `requirements.txt`; trainer binds to `FEATURE_ORDER` via SHA-256 `feature_order_hash` stamped at training + refused at inference load.
- DEC-065 — artifact-storage SUBSTITUTION (S3/Modal volume → private Supabase Storage `combiner-models/`); URI `storage://combiner-models/{model_id}/model.txt` with sibling `meta.json`.

## Lovable cannot run this trainer

These files are AUTHORED and COMMITTED by Lovable but cannot be executed in the Lovable sandbox — the trainer requires `lightgbm` (native binary), real Supabase connectivity with the service-role key, and live training data. The trainer is executed by the GHA workflow (operator-provisioned, separate package). The Python tests in `tests/` (the hash test + the skip-gate test) and the parity-assert script ARE runnable in the Lovable sandbox without LightGBM.

## Promotion model

The trainer ONLY ever writes `status='candidate'`. Promotion to `status='active'` is the job of the 3.3a `promote_combiner_model` RPC, gated on the criteria evaluator. The trainer does NOT promote, does NOT swap, does NOT touch live rankings.

## Skip-gracefully gate

T+10 forward-return labels accrue with a 10-RTH-day lag from the day MIG-115 widened the horizon CHECK (FP-052.3 / 3.3a). Until enough labels exist, training is a NO-OP (typed stdout line, exit 0). The weekly cron retries; no degenerate model is ever fit on thin data.
